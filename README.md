# Golden Good Joyería

Sitio de marketing / catálogo para Golden Good — oro 10k y 14k en Guadalajara, México.

## Stack

- Next.js App Router + TypeScript + Tailwind CSS v4
- CTAs → WhatsApp `wa.me/523327464052`
- Placeholders elegantes (sin fotos robadas)

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

## Páginas

- `/` Home
- `/catalogo` con filtros 10k/14k, tipo, ocasión
- `/catalogo/[slug]` fichas de producto
- `/colecciones`
- `/nosotros`
- `/envios`
- `/faq`
